# Smart-Car-Rental-Dynamic-Pricing-System-Sheetal-Kumar
Smart Car Rental Dynamic Pricing System using Algorithmic Models and Front-End Development Framework
The car rental industry is changing quickly and requires new technology to respond to market shifts. Fixed pricing often fails, leading to underused cars, lost revenue, and unhappy customers. This article presents and evaluates a smart car rental pricing system that dynamically adjusts prices. It responds to demand, location, weather, and events. The system uses a React front end and smart algorithms for decision-making. The project aims to ensure fair, transparent pricing, enhance fleet use, and boost profits by using weighted algorithms and feedback learning. It is built with a clear step-by-step process for strong design, testing, and launch. The model adjusts prices across many scenarios, helping more cars be rented and increasing profits in tests. Using artificial intelligence and modern web technology, the project unites research with practical use.

Overview of the Proposed Framework
The proposed system is designed to build a smart, web-based car rental pricing and management tool that adjusts rental prices in real time based on factors such as location, demand, weather, and the number of events. The system uses React for the front end, Python for smart decision-making, and shows data with live charts and dashboards.
The system is built step by step, following a planning, analysis, design, build, test, and launch process, to ensure it works well and is easy to maintain. The front end (React) provides users and admins with an interactive way to view car availability and prices in real time. The back end (Python/Flask) runs the pricing algorithm and communicates with the front end via APIs. The database (SQLite or MongoDB) keeps information about vehicles, rental history, and other details used for price calculations.
At its core, the system makes decisions using several factors, mixing set rules and smart algorithms. The design can evolve in the future, enabling the addition of machine learning, such as learning from feedback, to improve pricing.
